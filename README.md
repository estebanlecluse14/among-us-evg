# Among Us EVG — The Skeld Mission Control

Web-app pour un Among Us grandeur nature.

## Version actuelle
- Création d'une partie avec code à 4 caractères
- Interface console centrale
- Interface joueur mobile
- 5 missions physiques
- Barre de progression
- Journal des validations
- Alerte REPORT
- Synchronisation de démonstration entre onglets du même navigateur

## Étape suivante
Brancher une base de données temps réel gratuite afin que plusieurs téléphones puissent rejoindre la même salle via Internet, puis publier le site.

Les missions sont adaptées du kit de jeu fourni par l'organisateur.
